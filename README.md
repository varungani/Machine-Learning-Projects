# 🤖 Machine Learning & Deep Learning Repository

This repository contains organized implementations of Machine Learning (ML) and Deep Learning (DL) projects.

## 📁 Folder Structure

- `ml/`  
  Contains classical machine learning notebooks including regression, KNN, clustering, etc.  
  Includes a `datasets/` subfolder for ML-related tabular datasets.

- `dl/`  
  Contains deep learning notebooks divided into three subfolders:
  - `classification/`: DL-based classification tasks
  - `nlp/`: Natural Language Processing tasks
  - `cv/`: Computer Vision tasks  
  A `datasets/` subfolder is included for datasets used in DL projects (mainly from TensorFlow and PyTorch libraries).

## 🛠️ Dependencies

Install all required packages using:
```bash
pip install -r requirements.txt
```

## 📌 Notes

- All notebooks are organized topic-wise for clarity.
- ML projects use structured/tabular data.
- DL projects use standard datasets accessed via `torchvision` or `tensorflow_datasets`.
